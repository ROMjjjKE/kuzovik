# Кузовик: антикоррозионная обработка, Гомель

Готовый статический сайт. Без сборки, без зависимостей: откройте `index.html` или залейте содержимое папки на хостинг.

Живая версия: https://romjjjke.github.io/kuzovik/
Репозиторий: https://github.com/ROMjjjKE/kuzovik

## Что внутри

| Файл | Назначение |
| --- | --- |
| `index.html` | лендинг: герой со сравнением «до/после», проблема, система покрытия, объекты, расчёт и оплата, адрес, FAQ, форма |
| `politika.html` | политика обработки персональных данных |
| `assets/css/style.css` | токены, сетка, компоненты, адаптив, анимации |
| `assets/js/main.js` | меню, ползунок сравнения, подсветка слоёв, валидация формы |
| `assets/img/` | фотографии (демонстрационные) |

## Что заменить перед продажей

1. **Фотографии.** Все снимки сгенерированы для демонстрации. Замените файлы в `assets/img/`, сохранив имена и пропорции: `rust.jpg` и `coated.jpg` должны быть одного кадра и одной пропорции, иначе сравнение будет выглядеть нечестно.
2. **`[УНП]` и `[email]`** в `politika.html`.
3. **Соцсети и WhatsApp.** Номер WhatsApp задан в `assets/js/main.js` (`CONFIG.whatsapp`) и в ссылках `wa.me` в разметке.
4. **Адрес, часы, география.** Проверьте формулировки про выезд за пределы Гомеля: сейчас написано «обсуждаем по телефону».

## Заявки

Форма валидирует имя и телефон и собирает текст заявки. По умолчанию после отправки показываются две кнопки: звонок и WhatsApp с готовым текстом.

Чтобы заявки приходили на почту или в CRM, впишите адрес обработчика в `assets/js/main.js`:

```js
const CONFIG = { formEndpoint: 'https://formspree.io/f/xxxxxxx' };
```

Обработчик получит JSON: `name`, `phone`, `work`, `details`.

## Анимации и доступность

- Появление блоков сделано на CSS `animation-timeline`: без JavaScript контент виден.
- Ползунок сравнения работает мышью, пальцем, стрелками клавиатуры и имеет подпись для скринридеров.
- При `prefers-reduced-motion: reduce` все анимации отключаются.
- Контраст текста и кнопок не ниже 4.5:1, все интерактивные элементы имеют `:focus-visible`.

## Проверки

- `sloplint` (Nutlope/hallmark): 0 FAIL, 0 REFLEX, 0 WARN.
- Все страницы и ассеты отвечают 200 на GitHub Pages, консоль без ошибок.

## Публикация

Уже опубликовано через GitHub Pages из ветки `main`. Свой домен: Settings → Pages → Custom domain, затем заменить адрес в `index.html` (canonical, `og:url`, `og:image`), `politika.html`, `sitemap.xml`, `robots.txt`.

Альтернативы: Netlify Drop, Vercel, Cloudflare Pages, обычный хостинг (`public_html`). HTTPS обязателен.
